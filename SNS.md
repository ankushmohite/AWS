
AWS SNS (Simple Notification Service) is an AWS service used to send notifications or messages to multiple subscribers, such as email, SMS.

1. SNS Topic.
An SNS Topic are like a communication channel between published and subscribers.

2. Subscriber.
A Subscriber is the person that receives messages from an SNS topic.

SNS is push base because it send massege to subscribers.

SNS Protocol:
HTTP, HTTPS, Email. SMS.
